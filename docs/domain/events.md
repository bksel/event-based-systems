# Event catalogue

Source: project proposal, Section 2.2. This is the authoritative list of event names. Code,
model and reports use these names exactly.

## Observable, uncontrollable events (`E_obs`)

Generated by the user and the sensors. The controller cannot prevent them.

| Event | Category | Notes |
|---|---|---|
| `power_on` | user | |
| `order_espresso` | user | |
| `order_americano` | user | |
| `order_cappuccino` | user | |
| `temp_reached` | completion | Ends both `heat_to_brew` and `heat_to_steam` |
| `grind_done` | completion | Ends `start_grind` |
| `brew_done` | completion | Ends `start_brew` |
| `steam_done` | completion | Ends `start_steam` |
| `hot_water_done` | completion | Ends `add_hot_water` ([ADR 0009](../decisions/0009-fix-recipe-stages-and-completion-events.md)) |
| `water_empty` | fault | |
| `beans_empty` | fault | |
| `milk_empty` | fault | |
| `bin_full` | fault | Grounds container full |
| `refill_water` | service | |
| `refill_beans` | service | |
| `refill_milk` | service | |
| `empty_bin` | service | |

## Controllable events (`E_con`)

Chosen by the controller when enabled (`e ∈ EF(s)`) and safe (`safe(s, e)`).

| Event | Completed by | Notes |
|---|---|---|
| `heat_to_brew` | `temp_reached` | |
| `heat_to_steam` | `temp_reached` | |
| `start_grind` | `grind_done` | |
| `start_brew` | `brew_done` | |
| `add_hot_water` | `hot_water_done` | Americano only |
| `start_steam` | `steam_done` | |
| `eject_grounds` | (instant) | `g := g + 1` |

## Fault → service pairs

Service events are possible when the corresponding fault is active. Fault classes and blocked
resources are in [drinks and resources](drinks-and-resources.md#bf-resources-disabled-by-each-fault)
([ADR 0010](../decisions/0010-fault-classes-blocked-resources-and-fault-exits.md)).

| Fault | Cleared by | Notes |
|---|---|---|
| `water_empty` | `refill_water` | |
| `beans_empty` | `refill_beans` | |
| `milk_empty` | `refill_milk` | |
| `bin_full` | `empty_bin` | Also resets the grounds counter, `g := 0` |
