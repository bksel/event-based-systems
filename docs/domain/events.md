# Event catalogue

Source: project proposal, Section 2.2. This is the authoritative list of event names. Code,
model and reports use these names exactly.

## Fault → service pairs

The proposal says service events are possible when the corresponding fault is active. This is
the mapping implied by the names. Rows marked **?** have no obvious service event.

| Fault | Cleared by | Notes |
|---|---|---|
| `water_low` | `refill_water` | Warning only? See [Q4](../open-questions.md#q4-faults-without-a-service-event) |

| `beans_empty` | `refill_beans` | |
| `milk_empty` | `refill_milk` | |
| `bin_full` | `empty_bin` | Also resets the grounds counter `g`? |
| `tray_full` | `empty_tray` | |
| `brew_unit_removed` | `insert_brew_unit` | |
| `flow_error` | **?** | See [Q4](../open-questions.md#q4-faults-without-a-service-event) |
